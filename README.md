Project Title

Livestock Daily Counting and Weight Comparison System

Project Explanation

This project involves the design and implementation of an automated livestock monitoring system using a Programmable Logic Controller (PLC). The system is developed to help farmers or farm managers accurately count livestock daily and monitor their weight, reducing manual work and human error.

The system automatically detects each animal as it passes through a designated point (such as a gate or weighing platform), counts the animal only once per day, and measures its weight using a weight sensor. The measured weight is then compared to predefined weight categories (for example: underweight, normal, or overweight). All data is stored and displayed for monitoring and decision-making.

Objectives of the System

The main objective of this project is to automate livestock counting and weight comparison using PLC technology in order to improve accuracy, efficiency, and livestock management.

How the System Works
1. Automatic Animal Detection and Counting

A sensor (such as an infrared or proximity sensor) detects an animal as it passes through a gate or weighing platform.

The PLC registers the detection and increments the daily count.

Logic is programmed to ensure that each animal is counted only once per day, even if it passes multiple times.

2. Weight Measurement

A load cell (weight sensor) measures the weight of each animal as it stands on the weighing platform.

The weight signal is sent to the PLC, where it is converted into a readable value (kilograms).

3. Weight Comparison

The measured weight is automatically compared with predefined weight thresholds stored in the PLC.

Based on the comparison, the animal is classified into a weight category, such as:

Underweight

Normal weight

Overweight

4. Data Storage and Display

The system stores:

Total number of animals counted per day

Individual weight readings

Weight category results

Information is displayed on an HMI (Human–Machine Interface) or digital display for easy monitoring by the user.

5. Daily Reset Function

At the start of a new day, the system automatically resets the daily count using a timer or real-time clock.

A manual reset button is also included to allow the user to reset the system when necessary.
